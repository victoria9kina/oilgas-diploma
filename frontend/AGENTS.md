Frontend Project Instructions

Project context

This is a university project.
The backend is already completed and submitted.
Work only on the Angular frontend.

Main objective

Meet every mandatory frontend requirement.
Preserve existing working functionality.
Make the code easy to understand and explain.

Architecture

Keep the existing Angular architecture.

Do not rewrite the application.

Do not introduce NgRx, CQRS, Clean Architecture
or unnecessary design patterns.

Avoid unnecessary components, services and interfaces.

Prefer simple TypeScript and Angular solutions.

Use existing dependencies whenever possible.

Backend restrictions

Backend is read-only.

Never modify backend files.

Never invent API endpoints or request fields.

Check actual API contracts before changing requests.

Do not change backend business logic.

Implementation rules

Inspect files before editing.

Make small, isolated changes.

Do not modify unrelated files.

Do not remove working functionality.

Do not add dependencies without explicit justification.

Explain non-obvious implementation decisions.

Prefer the simplest solution that meets the requirement.

Verification

After each task:

Run the relevant checks.

Run Angular build when appropriate.

Run tests when appropriate.

Report actual results.

Distinguish verified functionality from assumptions.

Never claim success without verification.

Git safety

Never execute destructive Git commands.

Never delete project files or dependencies without approval.

Never commit or push without explicit permission.

Never include node_modules, secrets or environment files
containing credentials in Git.

Priority

Correctness > assignment compliance > simplicity > visual polish.

Do not overengineer this student project.
